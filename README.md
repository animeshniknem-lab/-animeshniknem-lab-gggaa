# Гримуар d20 — Виртуальный игровой стол

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

**Гримуар d20** — это современный виртуальный игровой стол для настольных ролевых игр (D&D, Pathfinder и других d20-систем). Приложение работает прямо в браузере, не требует установки и поддерживает синхронизацию между игроками.

## ✨ Особенности

### 🎲 Броски кубиков
- Поддержка всех классических кубиков: d4, d6, d8, d10, d12, d20, d100
- Сложные формулы с модификаторами
- История бросков с деталями
- Анимация критических успехов и провалов

### 🗺 Игровой стол
- Загрузка карт из библиотеки
- Перетаскиваемые фишки персонажей
- Сетка с настраиваемым масштабом (5ft, 10ft, 1m, 2m)
- Секретные маркеры для Мастера
- Синхронизация состояния стола между игроками

### 🎵 Музыкальное сопровождение
- Загрузка аудиофайлов в плейлист
- Управление воспроизведением (play/pause/stop)
- Синхронизация музыки между всеми участниками
- Регулировка громкости

### 👥 Мультиплеер
- Создание комнаты с уникальным кодом
- Подключение игроков по коду комнаты
- Отображение присутствующих за столом
- Чат для общения
- Синхронизация бросков, карт и музыки

### 📚 Библиотека контента
- **Персонажи**: создание и хранение листов персонажей
- **Квесты**: отслеживание сюжетных линий и наград
- **Заметки**: игровые записи и хроники
- **Инвентарь**: управление предметами и снаряжением
- **Монстры**: справочник существ с характеристиками
- **Правила**: быстрая справка по игровым механикам

## 🚀 Быстрый старт

### Для игроков
1. Откройте `index.html` в любом современном браузере
2. Выберите роль (Мастер или Игрок)
3. Введите имя персонажа
4. Нажмите "Войти"

### Для Мастера
1. Откройте `index.html` в браузере
2. Выберите роль **Мастер**
3. Создайте комнату — вы получите уникальный код
4. Поделитесь кодом с игроками
5. Загрузите карту, добавьте музыку и начните игру!

### Для подключения к игре
1. Откройте `index.html`
2. Выберите роль **Игрок**
3. Введите код комнаты, который дал Мастер
4. Нажмите "Войти в комнату"

## 🛠 Технологии

- **HTML5** — семантическая разметка
- **CSS3** — стилизация с CSS Variables
- **Vanilla JavaScript** — без фреймворков
- **IndexedDB** — локальное хранилище данных
- **PeerJS** — P2P соединение между игроками
- **Web Audio API** — воспроизведение музыки
